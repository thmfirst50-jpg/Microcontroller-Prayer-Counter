# Microcontroller Prayer Counter

A portable Arduino Nano device that detects movement and displays the current prayer stage.

## Goal

Track movement-driven stages in a compact, rechargeable embedded device.

## Design and implementation

Implemented a finite state machine in C/C++ and filtered infrared proximity readings to trigger stage transitions. Drove a 7-segment display for real-time feedback.

## Project highlights

Integrated a rechargeable lithium-ion battery circuit with a TP4056 charging module to support portable use.

## Technologies

- Arduino Nano
- C/C++
- FSM
- IR sensing

This repository currently contains the project overview. Source code, design files, test data, and project photos have not been uploaded here. The description documents the project; it is not a runnable software release.
